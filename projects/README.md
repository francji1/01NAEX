# Team projects

Two team projects are assigned during the semester. The assignment of each project is published in this folder
as `01NAEX_ProjectN.ipynb` together with its deadline.

| Project | Assignment | Deadline |
|---|---|---|
| 1 | [`01NAEX_Project1.ipynb`](01NAEX_Project1.ipynb) - the pendulum experiment | Sunday 8 November 2026 |

Submit the project by pull request as `projects/01NAEX_ProjectN_<Surname1>_<Surname2>_....ipynb`
(one notebook per team, surnames joined with underscores, with outputs). If the project uses your own measurements, add the raw
data as `projects/01NAEX_ProjectN_<Surname1>_<Surname2>_....csv` with the same name. Keep the file name pattern and do not
change other files.
