# Team projects

Two team projects are assigned during the semester. The assignment of each project is published in this folder
as `01NAEX_ProjectN.ipynb` together with its deadline.

Submit the project by pull request as `projects/01NAEX_ProjectN_<Surname1>_<Surname2>_....ipynb`
(one notebook per team, surnames joined with underscores). Keep the file name pattern and do not change other files.
